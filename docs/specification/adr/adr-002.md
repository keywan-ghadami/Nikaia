# ADR-002: A Toolchain That Wraps Cargo, and Metaprogramming Without Proc-Macros

**Status:** Accepted, except §4 · **Built:** no
**Superseded in part by:** [ADR-003](adr-003.md) — the five-phase pipeline that
hijacked `rustc` per language; see §4. D3's Cranelift claim by
[ADR-021](adr-021.md) D9.
**Related:** [ADR-021](adr-021.md) (works out D3), [ADR-026](adr-026.md)
(works out D2), [ADR-007](adr-007.md) (the multi-language goal)

## 1. Context

Nikaia is one language on a toolchain meant to host several. Two things had to
be true before any of them: a Nikaia project must consume crates.io without
reinventing dependency resolution, and compile-time metaprogramming must not
cost what Rust's proc-macros cost — a separate dynamic library compiled before
the program that uses it.

## 2. Decisions

### D1 — One CLI wraps and instruments Cargo.

`nikaia.toml` is translated to a compliant `Cargo.toml`, native Rust
dependencies passing through unchanged. Compilation is intercepted with
`RUSTC_WORKSPACE_WRAPPER`: Rust crates go to the native `rustc`, `.nika` files
to the Nikaia pipeline. The build switches of [ADR-037](adr-037.md) set
`opt-level` and the panic strategy from there.

Dependency resolution and linking are solved problems, and a language that
cannot reach crates.io starts with no ecosystem.

### D2 — Compile-time code runs in an interpreter, not as a compiled plugin.

Quasi-quoting, `dsl … { … }` validation and reading a file at build time are
evaluated by an AST walker in the compiler's own process.

A proc-macro is a crate that must be built, linked and loaded before the crate
that uses it, which is where Rust's build latency comes from. An interpreter has
none of that, and the compiler already holds the AST.

What a build may read, and what may run while it reads, is [ADR-026](adr-026.md)
— still open.

### D3 — A build that reads the world needs a deterministic key over what it read.

Every external file a compile-time evaluation touches is recorded by content
hash in a lockfile, and an unchanged hash skips the evaluation.

[ADR-021](adr-021.md) is this decision worked out: what is hashed, what
invalidates what, and where artifacts live. Where the two differ, ADR-021 wins.

## 3. Consequences

Rust's own guarantees are inherited rather than rebuilt — the borrow checker
verifies the lowered program, which is what lets Nikaia promise memory and
thread safety without implementing either.

The price is stated in [ADR-001](adr-001.md) D1: linking `rustc_private` pins
the toolchain to one nightly, and a target language has to fit Rust's ownership
model. A language that assumes pervasive garbage collection does not.

## 4. History — what ADR-003 replaced

This record specified five phases, of which Phase 3 hijacked
`rustc_interface`'s `override_queries` to hand the compiler a hand-built
`rustc_ast::Crate` in memory, per language.

[ADR-003](adr-003.md) replaced that with **Bridge-IR** and one generic
orchestrator: the cost of the original design was that every new language
re-implemented the whole cargo-wrapping and compiler-bootstrapping layer.

D1 to D3 are about the toolchain's outside, not that coupling, and stand.
