# ADR-077: The Word Is `comptime`, Because a Keyword Should Say *When* and Not *Whether It Changes*

**Status:** Accepted · **Built:** yes — see §4
**Date:** September 14, 2026
**Amends:** [ADR-073](adr-073.md) D1's **spelling** and nothing else. Every
decision that record makes about what the declaration *means* stands unchanged
**Related:** [ADR-051](adr-051.md) D1 (a name may not be a reserved word),
[ADR-071](adr-071.md) D3 (a word is reserved against the possibility of a
construct, and un-reserving is the free direction), Part I 2.1 (mutability is
what `mut` says), Part II 10.2

---

## 1. Context

[ADR-073](adr-073.md) reserved `const` and built the declaration under that
name. The name is the one every language in the neighbourhood uses, which is why
it was picked without an argument — and it is wrong here for a reason that only
shows up in this language.

**`const` names immutability, and every binding in Nikaia already has it.** Part
I 2.1 is explicit: a `let` cannot be assigned again unless it says `mut`. So a
keyword whose meaning is *this one does not change* would be a keyword that
distinguishes nothing. A reader who knows the language would ask what it adds,
and the honest answer would be *nothing you could not already assume*.

What the declaration actually promises is a **time**: this is evaluated while the
program is built, and if it cannot be, the program is refused
([ADR-073](adr-073.md) D3). That is what the word should say.

## 2. Decisions

### D1 — The declaration is spelled `comptime`.

```nika
comptime LIMIT = 4 * 1024
```

The word names the stage rather than a property of the binding. Zig is the
precedent and it is worth naming as one: the language that made compile-time
evaluation a first-class stage did not call it `const` either, and calls
*its* immutable binding `const` — the opposite assignment from the one here,
for a language whose default is the other way round.

### D2 — `const` stays reserved, and is not a construct.

It goes back to being what [ADR-071](adr-071.md) D2 calls a word reserved
against the possibility of a construct rather than for one. A program may not
use it as a name.

The reason to keep it rather than release it is the polarity
[ADR-050](adr-050.md) D7 recorded and [ADR-071](adr-071.md) D3 leaned on:
**un-reserving is the free direction and reserving is not.** `const` is the
first thing a reader arriving from another language will type, and a word that
is reserved can be given a message; a word that is a name cannot.

### D3 — Nothing else about the declaration changes.

[ADR-073](adr-073.md) D2 through D6 stand as written: where it may stand, that
the type may be left out, that the fold *must* succeed, what may be in the
initialiser, and that it is a value rather than a place. This record is about
one word.

**And the word does not travel downwards.** What the emitter writes is Rust's
`const`, because that is Rust's name for the same slot. The two languages
disagree about which word means what, and the translation is where that stops
mattering.

## 3. Consequences

**One keyword more, not one instead.** The reserved list goes from 33 to 34:
`comptime` joins it and `const` stays, so a program that writes either is told
something rather than being surprised.

**`NK1127` keeps its number and changes one word** — *"a `comptime` is a `let`
that must fold"*. The code was never about the spelling.

**A reader of the generated file sees both words**, one per language, and the
test that covers the lowering says which is which where it could otherwise read
as an inconsistency.

## 4. What is built

**Yes.** `comptime` is the 34th reserved word and the statement's keyword;
`const` is reserved and parses nowhere. The six tests of
`crates/nikaia/tests/comptime.rs` are the same ones, renamed with the word, and
one of them compiles and runs the program.

What is **not** built is what was not built before this record either: the item
form ([`open-work.md`](../../open-work.md) §2.14) and the second stage of what an
initialiser may hold ([ADR-073](adr-073.md) D5).
