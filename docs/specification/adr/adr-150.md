# ADR-150: A Duration Is `std::time::Duration`, and It Is Written `5.seconds()`

**Status:** Accepted · **Built:** no — see §5
**Date:** September 19, 2026
**Target Version:** Nikaia 0.0.31
**Related:** [ADR-141](adr-141.md) D2 (which marked the page *unspecified*),
[ADR-136](adr-136.md) §4 (no suffix on a number literal, and why),
[ADR-060](adr-060.md) (a literal takes its type from its use),
[ADR-028](adr-028.md) D5 (an entry exists because a program asked for it),
Part II 12.4, Part III 13.3 (`cleanup-deadline`, which is already a duration
in a manifest)

## 1. Context

Part II 12.4's `sleep(5.seconds())` writes a value of a type nothing declares,
and [ADR-141](adr-141.md) D2 marked it *unspecified*. The type is not in
dispute — a duration is a duration — so what is left is where it lives and how
it is spelled.

The manifest already has one: `cleanup-deadline` is a duration a person writes
in a `.toml`. What has never existed is the value a program holds.

## 2. Decisions

### D1 — The type is `std::time::Duration`.

A `std` type, not a language one. It carries a span of time and nothing else,
it is a value that copies, and it is what `sleep`, a timeout and a deadline
take.

### D2 — It is written `5.seconds()`, as a method on an integer.

```nika
sleep(5.seconds())
sleep(250.millis())
let deadline = 2.minutes()
```

An extension `std::time` provides — `seconds`, `millis`, `micros`, `minutes`,
`hours` on the integer types — beside the constructors
(`Duration::seconds(5)`) for a computed count.

**It is what the pages already write**, which is not a small argument: the
spelling was chosen by whoever wrote the example, and it reads the way the
sentence does.

### D3 — There is no suffix literal, and that is [ADR-136](adr-136.md) kept.

`5s` and `250ms` would be a literal form that record declined for numbers, on
the ground that *the digits a number is written in are a spelling and the use
gives the type*. Reopening it for one type would make the rule *a literal has
no suffix, except for durations* — and a rule with an exception in it is a
rule a reader has to remember rather than one they can apply.

### D4 — It is `std`'s, so the language learns nothing.

No keyword, no literal, no type in the grammar. What this costs the **language**
is nothing at all; what it costs `std` is a type and a trait implementation.

## 3. Consequences

* Part II 12.4's `sleep(5.seconds())` becomes a program, and the mark leaves
  the page for that half of it.
* [ADR-148](adr-148.md)'s `select` has the value its timeout arm needs.
* The literal rule stays whole.
* **What it costs:** one `std` type, its entries, and the integer extension.

## 4. What this does not decide

* **A clock**: what *now* is, and whether it is monotonic. A duration is a
  span; an instant is a different value and a different question.
* **A duration in a manifest becoming this type.** `cleanup-deadline` is read
  by the build, not by a program, and the two meeting is a question nobody has
  asked.
* **Arithmetic on durations** beyond what the type obviously has; the entries
  exist because a program asked ([ADR-028](adr-028.md) D5).

## 5. What is built

Nothing. `5.seconds()` is a method on an integer that no ledger describes. The
order of work:

1. `std::time::Duration` and its entries;
2. the integer extension, five names;
3. `sleep` taking one, which is the call the page writes;
4. Part II 12.4's line as a test that runs.

`docs/open-work.md` carries it.
