# ADR-116: `from` Is a Name, and a File a Build Reads Is `asset("…")`

**Status:** Accepted · **Built:** no — see §5
**Date:** September 16, 2026
**Target Version:** Nikaia 0.0.8
**Related:** [ADR-051](adr-051.md) (the reserved list, which loses a word),
[ADR-072](adr-072.md) (a file a build reads is named three times — the code's
spelling changes, the rule does not), [ADR-082](adr-082.md) D4 (which had kept
the word for this), [ADR-026](adr-026.md) D2 (a build-time path stays inside
the project), [ADR-076](adr-076.md) (names the language below reserves are
escaped, so Rust does not decide this list), Part I 2.1, Part II 10.6,
Part III 13.1 and 17.1

## 1. Context

`from` was reserved, and it bought one phrase: `Json.value(from
"config.json")`, the read of a file at build time, checked against an
allowlist and embedded in the binary. The parser used the word in one rule,
and that rule exists only to print a helpful message for the removed form
`dsl X from e`. Nothing live in the compiler parsed `from`.

What the word cost was itself. `from`/`to` is the pair every API reaches for
— renaming, copying, ranges, transfers, spans of time — and the
specification's own `fs::rename(from: Path, to: Path, …)` could not be
written in the language, because a reserved word is a name only after `::`
and `.`. A test's countdown had already been renamed from `from` to `start`
to make room.

The reserved list was chosen when there were no programs outside this
repository, on the ground that the choice was free then in a way it would
never be again. The same ground makes freeing a word free today.

## 2. Decisions

### D1 — `from` is an ordinary name.

It leaves the reserved list in Part I 2.1 and in the parser's table.
`fn rename(from: Path, to: Path)`, `let from = 10`, `p.from` are what they
look like. The parser's message for the removed `dsl X from e` matches the
bare word, and loses nothing.

### D2 — A file a build reads is `asset("…")`.

```nika
comptime CONFIG: Json::Value = Json.value(asset("config.json"))
comptime ROUTES = Routes.table(asset("routes.txt"))
```

`asset` is the compiler's, not `std`'s: it is recognised inside a `comptime`
initialiser, its argument is a string literal and may not be computed, the
path is under the project root, and the literal is what the allowlist is
checked against — every rule [ADR-072](adr-072.md) states holds unchanged,
under a call rather than a keyword. The word is the one Part III 13.1 already
uses for what these files are (*asset hashing*). Written anywhere but a
`comptime` initialiser it is refused, and the message says that a file read
while the program runs is `fs::read`.

### D3 — `std` writes `from:` where it meant to.

`fs::rename(from: Path, to: Path, root: Root)` and `fs::copy(from:, to:,
root:)` parse as Part III 17.1 has them.

## 3. Consequences

* One word fewer that a reader has to know is forbidden, and the most
  common one.
* The build-time read reads as a call, which is what it is, beside the call
  that consumes its bytes: `Json.value(asset("config.json"))` says *when*
  (`comptime`), *where from* (`asset`) and *what with* (`Json.value`) in the
  same three places the keyword did.
* Nothing in the language below is touched: Rust does not reserve `from`,
  and a name Rust does reserve is escaped anyway ([ADR-076](adr-076.md)).
* **What it costs:** the word out of two tables, one intrinsic recognised in
  the checker, and the specification's examples.

## 4. What this does not decide

* The other reserved words. Each is its own question, asked next; the answer
  here is only that a word whose sole use is a phrase the language can say
  another way does not earn a place on the list.
* Whether `asset` may one day mean *these bytes, embedded* outside
  `comptime`. Refused today, and a later record may allow it.

## 5. What is built

Nothing. `from` is in `parser::RESERVED_WORDS`, and the build-time read is
not built in either spelling ([ADR-072](adr-072.md) §4, [ADR-073](adr-073.md)
D5). The order of work:

1. `from` out of the parser's table and the `dsl X from e` message matching
   the word;
2. `asset("…")` recognised in a `comptime` initialiser, with the literal
   check and the refusal elsewhere, when [ADR-073](adr-073.md)'s second stage
   lands;
3. the two `fs` entries in `std.contracts`.

`docs/open-work.md` carries it.
